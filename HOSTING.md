# Публикация EuroAuto через GitHub Pages

Проект — статический многостраничный сайт. Workflow в `.github/workflows/pages.yml` автоматически публикует его в GitHub Pages после каждого коммита в `main`.

Откройте **Settings → Pages** репозитория и выберите **GitHub Actions** в разделе **Build and deployment**. После завершения первого workflow сайт станет доступен по адресу `https://fllowey.github.io/euroauto/`.
